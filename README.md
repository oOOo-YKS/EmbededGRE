# EmbeddedGRE 🔴📈

**EmbeddedGRE** is an AI-powered tool that moves away from alphabetical GRE lists. It uses **Vector Embeddings** to group words by their functional meaning and intensity.

## 💡 The Problem
A-Z lists group "Abase" and "Abash" together because they start with 'A'. In reality, they are related because they both involve **social impact on others.**

## 🛠️ The Solution
Using the `all-MiniLM-L6-v2` model, this project maps 3,000 words into a high-dimensional vector space. 
- **Causative Cluster:** Words like *Galvanize*, *Goad*, and *Kindle*.
- **Diminishing Cluster:** Words like *Abate*, *Wane*, and *Ebb*.
